# Муся & Матусевич — Wedding Demo v0.2

Персональное интерактивное свадебное приглашение — первый прототип будущей студии заказных приглашений.

## Запуск
Откройте `index.html` в браузере.

Лучше запускать через простой локальный сервер:
- VS Code → Live Server
- или `python -m http.server 8000`

После этого открыть `http://localhost:8000`.

## Фото
Положить реальные изображения в `assets/images/` под именами:
- `wedding_registry.jpg` — главный экран
- `kaliningrad_us.jpg` — история / Калининград
- `proposal.jpg` — предложение
- `wedding_kazan.jpg` — свадьба
- `belarus_flowers.jpg` — полноэкранный фотоблок

Имена взяты из ранее использованных вами материалов, поэтому после копирования файлов ничего в HTML менять не надо.

## Музыка
Положить выбранный трек:
`assets/audio/our-song.mp3`

Из-за правил браузеров музыка не запускается автоматически: гость нажимает кнопку «Музыка».

## RSVP
Сейчас форма полностью работает в демонстрационном режиме:
- ответ сохраняется в localStorage браузера;
- `admin.html` показывает ответы;
- есть статистика;
- ответы можно выгрузить в CSV.

Для настоящего заказа в `config.js` указывается `rsvpEndpoint`.
Тогда форма отправляет JSON POST на backend/API.

Пример payload:
```json
{
  "id": "...",
  "createdAt": "...",
  "name": "Сергей и Анна",
  "attendance": "Да, буду",
  "guests": 2,
  "food": ["Мясо"],
  "drinks": ["Вино"],
  "comment": "Нужен трансфер"
}
```

Backend затем сможет:
1. сохранить ответ в базе;
2. отправить уведомление на email;
3. отправить его в Telegram;
4. позднее — MAX / VK;
5. сформировать общую таблицу гостей.

## Что это уже доказывает как бизнес-прототип
- уникальный дизайн без публичного конструктора;
- повторно используемые внутренние компоненты;
- персональные фото, тексты и музыка;
- мобильная адаптация;
- рабочая анкета;
- будущая интеграция уведомлений без изменения самой страницы.
