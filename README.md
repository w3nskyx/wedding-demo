# Муся & Матусевич — v0.3
Дизайн и функции v0.2 сохранены. Добавлены `weddingId`, общий FastAPI + SQLite backend, серверная валидация, закрытая HTTP Basic админ-панель и CSV. Публичная демо-админка удалена.

До развёртывания backend `rsvpEndpoint` оставлен пустым, поэтому фронт можно безопасно проверить локально. После развёртывания достаточно вписать HTTPS URL `/api/rsvp` в `config.js`.
